# tesla-miniapp 工程约定

## 字号（用户明确要求）

仪表盘整体是「小字号 + 留白」风格。新增或修改界面时，正文/标签默认对齐右侧
「电量」「车锁」这类面板标签的字号，不要用大字号。

| 用途 | 字号 |
| --- | --- |
| 面板标签（电量、车锁等） | 11rpx |
| 正文、次要信息、VIN、提示、信号强度 | 11rpx |
| 列表主文本、弹窗标题、按钮文字 | 12rpx |
| 徽标、极小标签（如「VIN 匹配」） | 10rpx |
| 强调数值（车速、电量百分比、续航） | 18–48rpx，沿用现有样式 |

新增弹窗、列表、按钮时，除非用户明确要求，字体大小保持在 10–12rpx 区间，
和「电量」「车锁」标签一致；行高和内边距可以保留，保证可点击区域。

参考实现：`pages/dashboard/dashboard.wxss` 的 `.scan-*`（设备选择弹窗）。
