在线烧录

Web Serial · USB-C 直连 · 无需 WiFi

01 / 连接电脑

用 USB-C 数据线把设备接到电脑，设备正常开机即可。

02 / 连接设备

用 Chrome / Edge 打开本页，点“连接设备”并选择串口；设备休眠时先触摸唤醒。

03 / 选择固件

点上方固件列表的“烧录”直接用站内镜像，或拖入本地 firmware.bin。

04 / 等待重启

写入备用 OTA 分区，CRC 校验通过后自动重启；NVS（旋转、亮度）保留。

未连接

需要 navigator.serial（Chrome / Edge 89+，https 或 http://localhost）。 串口监视器会占用同一串口，连接前请先关闭。首次连接需在弹窗里选一次串口； 之后只授权过一个设备时会自动连接，按住 Shift 点“连接设备”可重新选择。
